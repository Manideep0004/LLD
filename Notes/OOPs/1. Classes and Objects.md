
A **Class** is a blueprint, an **Object** is an instance.

```java
// Class Definition - Blueprint
public class Car {
    // Attributes (Fields)
    String brand;
    String color;
    int speed;
    
    // Constructor
    public Car(String brand, String color) {
        this.brand = brand;
        this.color = color;
        this.speed = 0;
    }
    
    // Methods (Behaviors)
    public void accelerate() {
        speed += 10;
        System.out.println(brand + " is accelerating! Speed: " + speed);
    }
    
    public void brake() {
        speed -= 5;
        System.out.println(brand + " is braking! Speed: " + speed);
    }
}

// Usage - Creating Objects
public class Main {
    public static void main(String[] args) {
        // Creating objects (instances)
        Car myCar = new Car("Tesla", "Red");
        Car yourCar = new Car("BMW", "Blue");
        
        myCar.accelerate();  // Tesla is accelerating! Speed: 10
        yourCar.accelerate(); // BMW is accelerating! Speed: 10
    }
}
