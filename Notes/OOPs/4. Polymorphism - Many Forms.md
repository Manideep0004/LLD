**Polymorphism** = Same method name, different behaviors (Overloading + Overriding).

### Method Overloading (Compile-time Polymorphism)

```java
public class Calculator {
    // Same method name, different parameters
    public int add(int a, int b) {
        return a + b;
    }
    
    public int add(int a, int b, int c) {
        return a + b + c;
    }
    
    public double add(double a, double b) {
        return a + b;
    }
    
    public String add(String a, String b) {
        return a + b; // String concatenation
    }
}

// Usage
public class Main {
    public static void main(String[] args) {
        Calculator calc = new Calculator();
        System.out.println(calc.add(5, 10));          // 15
        System.out.println(calc.add(5, 10, 15));      // 30
        System.out.println(calc.add(5.5, 10.5));      // 16.0
        System.out.println(calc.add("Hello", "World")); // HelloWorld
    }
}
```


### Method Overriding (Runtime Polymorphism)

```java
// Parent class
public class Animal {
    public void makeSound() {
        System.out.println("Animal makes a sound");
    }
}

// Child classes override the method
public class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Dog barks: Woof! Woof!");
    }
}

public class Cat extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Cat meows: Meow! Meow!");
    }
}

public class Cow extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Cow moos: Moo! Moo!");
    }
}

// Usage - Polymorphic behavior
public class Main {
    public static void main(String[] args) {
        // Parent reference, child object
        Animal myAnimal1 = new Dog();
        Animal myAnimal2 = new Cat();
        Animal myAnimal3 = new Cow();
        
        // Calls the overridden method of actual object
        myAnimal1.makeSound(); // Dog barks: Woof! Woof!
        myAnimal2.makeSound(); // Cat meows: Meow! Meow!
        myAnimal3.makeSound(); // Cow moos: Moo! Moo!
        
        // Array of Animals - all behave differently
        Animal[] animals = {new Dog(), new Cat(), new Cow()};
        for (Animal animal : animals) {
            animal.makeSound();
            // Output varies based on actual object type
        }
    }
}
```
